# Cambridge IGCSE Computer Science (0478 / 0984) — Curriculum Map

Learner: Vanishree (Year 11, Tanglin Trust School).

## Paper 1: Computer Systems (1h 45m, non-calculator)
1. `number-systems` — Denary, Unsigned Binary, Hexadecimal, Binary Addition/Overflow, Logical Shifts & 8-bit Two's Complement
2. `data-media-compression` — ASCII vs Unicode, Sound Sampling, Bitmap Images, IEC Units (`1024` KiB/MiB/GiB) & Lossless (RLE) vs Lossy Compression
3. `data-transmission` — Packets & Packet Switching, Serial/Parallel, Simplex/Half-Duplex/Full-Duplex, USB, Parity Bits/Blocks, Checksums, Echo Checks, Check Digits & ARQ
4. `hardware-architecture` — Von Neumann CPU & FDE Cycle, Input/Output Devices, Sensors (Monitoring vs Control), Primary/Secondary Storage, Virtual Memory, Cloud & MAC/IP/Routers
5. `software-security-ai` — System vs Application Software, OS & Interrupts, High/Low-Level Languages, Compilers vs Interpreters & IDEs, Internet Protocols, Cyber Security, Encryption, Automated Systems, Robotics & AI

## Paper 2: Algorithms, Programming & Logic (1h 45m, non-calculator)
6. `logic-gates` — NOT, AND, OR, NAND, NOR, XOR Gates, Logic Circuits, Truth Tables & Logic Expressions
7. `algorithms-testing` — Computational Thinking, PDLC, Flowcharts & CIE Pseudocode, Linear Search, Bubble Sort, Validation vs Verification, Test Data & Trace Tables
8. `python-arrays-sql` — Python & CIE Pseudocode Programming, String Handling, Subroutines & Scope, 1D/2D Arrays, File Handling & Single-Table SQL Databases
